## Описание

**SpaceBeast Analyzer** — профессиональный инструмент для визуализации занятого дискового пространства, выявления скрытых дубликатов, обнаружения неиспользуемых файлов и оптимизации файловой структуры. 

Приложение скомпилировано в виде единого исполняемого файла, работает на 100% автономно (без доступа к сети) и не требует предварительной установки .NET Runtime или внешних библиотек.

---

## Функциональные возможности

* **Высокоскоростное сканирование:** Реактивная многопоточная обработка сотен тысяч файлов и директорий за секунды.
* **Интерактивный анализ типов:** Сегментированная шкала распределения форматов (графика, видео, аудио, документы, архивы) с мгновенной фильтрацией файлового дерева в один клик.
* **Тепловая карта старения (Age Heatmap):** Цветовая маркировка файлов по времени их модификации (от зеленых «свежих» до красных файлов старше 1 года).
* **Поиск точных дубликатов:** Двухуровневый алгоритм (фильтрация по размеру + SHA-256 хеширование) для выявления 100% идентичных копий файлов.
* **Охотник за мусором (Junk Hunter):** Автоматическое обнаружение временных файлов (`.tmp`, `.log`, `.bak`, `.dmp`), кэшей и пустых директорий.
* **Режим «Топ-100 файлов»:** Сквозной список самых тяжелых файлов на всем просканированном накопителе.
* **Живой поиск и сортировка:** Мгновенная локальная фильтрация результатов без повторного обращения к диску.
* **Файловый менеджмент:**
  * Перемещение в системную корзину или безвозвратное физическое удаление с автоматическим пересчетом дерева.
  * Умная фоновая архивация директорий в ZIP с освобождением места.
  * Открытие объектов в нативном системном проводнике с автоматическим выделением файла (Windows Explorer / Linux DBus & XDG).
* **Встроенная справка:** Интерактивное руководство пользователя прямо внутри интерфейса.

## Загрузка и запуск

Готовые исполняемые файлы доступны в разделе **[Releases](../../releases)**.

### Windows (x64)
1. Скачайте `SpaceBeast-Windows-x64.exe` из последнего релиза.
2. Запустите файл (установка не требуется).
   > *Примечание:* При предупреждении SmartScreen выберите **«Подробнее»** ➔ **«Выполнить в любом случае»**.

### Linux (x64)
1. Скачайте `SpaceBeast-Linux-x64` из последнего релиза.
2. Предоставьте права на выполнение и запустите:
   `
   chmod +x SpaceBeast-Linux-x64
   ./SpaceBeast-Linux-x64
   `
